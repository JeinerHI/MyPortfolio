# ABP Set Pieces

**Elite football coaching landingpage for UEFA PRO Coach Bori Moreno.**

## Overview

ABPSetPieces.com is a business dedicated to coaching football coaches in setpieces plays, this project covers the landing page created for its business, following the brand identity with its fonts, colors, logos and more. The web has been deployed in a private VPS, setting wordpress locally and making use o nginx and pmp2 on the server.

The web is live on "abpsetpieces.com".
